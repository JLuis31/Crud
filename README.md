
# Inventory inflows and outflows

Application that allows creating, reading, updating, and deleting products using the Repository pattern and JWT-based authentication and Unit of Work.


## Run Locally

Clone the project

```bash
  git clone https://github.com/JLuis31/Crud.git
```

Go to the project directory

```bash
  cd Crud
```



## Tech Stack


- **Server:** C#, .NET
- **FrontEnd:** Js, React, CSS

## Features

- Api Post
- Api Get
- Api Delete
- Api Patch
